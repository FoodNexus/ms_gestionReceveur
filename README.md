Le MS Gestion Receveur est un microservice développé avec Spring Boot dans l’écosystème FoodNexus. Il permet de gérer les opérations liées aux receveurs, notamment la gestion des stocks, la déclaration des besoins, la réception des dons et l’évaluation des transactions. Il intègre également un système d’alertes automatiques ainsi que des fonctionnalités de prédiction des besoins futurs.
